Селектори CSS та специфічність

1. Селектор тега

Селектор p стилізує всі елементи цього тега на сторінках, де підключений спільний файл style.css

2. Селектор класу

Селектор.highlight стилізує всі елементи з даним класом на сторінках, де підключений спільний файл style.css

3. Селектор атрибута

Селектор [data-level="important"] вибирає елементи за значенням атрибута.

4. Дочірній селектор і селектор нащадка

  • Дочірній елемент: .menu > li додає синю лінію зліва.
    • Вкладений елемент: .menu > li його не вибирає, а .menu li li робить курсивним.
  • Другий дочірній елемент: лінія зліва теж є.

5. Псевдокласи :first-child, :nth-child, :last-child

  1. Перший елемент: li:first-child
  2. Другий елемент: li:nth-child(even)
  3. Третій елемент: без спеціальних правил
  4. Четвертий елемент: li:nth-child(even) і li:last-child

6. Псевдокласи :hover, :active, :focus

Навести курсор, натиснути або перейти клавішею Tab на посилання чи кнопку: :hover, :active, :focus.

Посилання

7. Конфлікт 1: ID проти класу й тегів

Правило #priority має специфічність (1, 0, 0), а правило p.conflict — (0, 1, 0). Застосовується #priority (зелений фон): порівняння йде зліва направо, тому один ID перемагає будь-яку кількість класів і тегів, навіть якщо це правило записано в CSS раніше.

8. Конфлікт 2: однакова специфічність

Правила .accent і .muted мають однакову специфічність (0, 1, 0). Застосовується .muted (сірий фон): за рівної специфічності перемагає правило, записане в style.css пізніше. Порядок назв у атрибуті class на результат не впливає.
